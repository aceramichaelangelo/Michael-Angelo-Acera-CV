# Michael Angelo Acera — Personal CV Website

## About
A professional personal CV website developed as an academic project and as the foundation of my online professional presence. Built with plain HTML, CSS, and JavaScript (no frameworks, no build tools).

## Features
- Responsive CV website (desktop, tablet, mobile)
- Personal profile and career objective
- Education, skills, and professional skills
- Projects with category filters (Web, Mobile, AI, UI/UX)
- Experience timeline
- Certifications with image modal
- GitHub / LinkedIn integration
- Downloadable CV (PDF)
- Interactive CV assistant (keyword-based chatbot, no AI API)
- Scroll animations, hover effects, loading screen, dark/light theme
- Responsive navigation and contact form with validation (mailto)

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla)

## Deployment
Deployed as a static site on Vercel (no build step; `index.html` is at the project root).

## Editing content
Personal links, email, projects, and certificates are edited in the `CONFIG`, `PROJECTS`, and `CERTS` lists at the top of `script.js`. Replace every `YOUR_...`, `PROJECT_...`, `FIGMA_URL`, and `ISSUER_NAME` placeholder.
